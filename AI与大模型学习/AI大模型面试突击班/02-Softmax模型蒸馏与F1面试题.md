# 02 - Softmax、模型蒸馏与 F1 面试题

> 来源：`AI大模型面试突击班.pdf` 第 13-27 页。

## 一、Softmax 公式

### 1. 公式

```text
softmax(z_i) = exp(z_i) / sum_j exp(z_j)
```

Softmax 把一个任意实数向量 `logits` 转换为概率分布。

### 2. 物理含义

- 非负性：指数函数结果大于 0，所以每一项概率都大于 0。
- 归一性：所有输出相加等于 1。
- 可解释性：可以把输出看成每个类别的概率。

### 3. 关键特性

#### 放大差异

Softmax 会放大较大 logit 和较小 logit 之间的差异。某个 `z_i` 比其他值大很多时，它的概率会接近 1，其他类别接近 0。

#### 平移不变性

```text
softmax(z_i) = softmax(z_i + C)
```

对所有 logit 加同一个常数，结果不变。这个性质是数值稳定实现的基础。

### 4. 数值稳定性

直接计算 `exp(z_i)` 可能出现上溢或下溢：

- `exp(1000)` 可能变成 `inf`。
- `exp(-1000)` 可能下溢为 0。

工程上通常先减最大值：

```text
softmax(z_i) = exp(z_i - z_max) / sum_j exp(z_j - z_max)
```

这样最大项变成 `exp(0)=1`，其余项小于等于 1，避免上溢。

### 5. 和交叉熵的关系

多分类任务里，Softmax 通常和 Cross Entropy Loss 一起用。PyTorch 的 `nn.CrossEntropyLoss` 会把 LogSoftmax 和 NLLLoss 合并计算，避免“先 Softmax 再 log”带来的数值精度问题。

### 6. Temperature 温度系数

```text
softmax(z_i / T)
```

- `T > 1`：分布更平滑，更适合知识蒸馏中的软标签。
- `T = 1`：普通 Softmax。
- `T < 1`：分布更尖锐，更接近 Argmax。

### 7. 面试回答模板

```
Softmax 的作用是把 logits 转成概率分布，公式是 exp(z_i) 除以所有 exp(z_j) 的和。它有两个重要特性：一是会放大类别差异，二是对整体平移不敏感。工程实现时不能直接算 exp(z)，因为大数会溢出，通常先减去最大 logit，再做指数和归一化。实际训练中 Softmax 往往和交叉熵融合计算，比如 PyTorch 的 CrossEntropyLoss。
```

## 二、模型蒸馏

### 1. 一句话定义

模型蒸馏是一种模型压缩技术，让小的学生模型学习大的教师模型的输出行为，在较小推理成本下获得接近教师模型的效果。

### 2. 硬标签 vs 软标签

传统训练只学习硬标签：

```text
猫: [0, 1, 0]
```

学生模型只知道“这是猫”，但不知道猫和其他类别之间的相似关系。

蒸馏训练学习教师模型的软标签：

```text
狗: 0.01
猫: 0.85
鸟: 0.14
```

这里的 `0.14` 表示“虽然答案是猫，但它和鸟有一些相似性”。这种类别之间的关系被称为 Dark Knowledge。

### 3. 温度系数 T 的作用

蒸馏时会用较大的 `T` 软化分布，让非目标类别的概率差异更明显：

- 原来小到接近 0 的概率会被放大。
- 教师模型对“非正确类别之间的相似性判断”会更容易被学生学到。

### 4. 训练流程

1. 用较大的 `T` 计算教师模型和学生模型的概率分布。
2. 用 KL 散度衡量两者分布差异，作为蒸馏损失。
3. 学生模型还要用真实标签计算交叉熵损失。
4. 总损失通常写成：

```text
Loss = alpha * DistillationLoss + (1 - alpha) * StudentLoss
```

### 5. 为什么蒸馏有效

- 软标签包含类别间相似性，比 one-hot 信息更丰富。
- 教师模型输出更平滑，相当于一种正则化，能缓解学生模型过拟合。
- 如果教师是多个模型的集成，蒸馏可以把集成模型的能力压缩到单个模型里。

### 6. 常见扩展

- Logits Distillation：模仿教师模型最终输出。
- Feature-based Distillation：模仿中间层特征。
- Attention-based Distillation：模仿教师模型的注意力图。
- Self-Distillation：让模型自己的历史版本或不同分支做教师。

### 7. 面试回答模板

```
模型蒸馏就是让小模型学习大模型。它不只是学习真实标签，还学习教师模型输出的软标签。软标签里包含类别之间的相似关系，也就是暗知识。训练时通常用较大的温度系数 T 让分布变平滑，再用 KL 散度约束学生输出接近教师输出，同时保留学生对真实标签的交叉熵损失。这样学生模型能在更小参数量和更低推理成本下获得接近教师模型的泛化能力。
```

## 三、F1 Score

### 1. 公式

```text
Precision = TP / (TP + FP)
Recall = TP / (TP + FN)
F1 = 2 * Precision * Recall / (Precision + Recall)
```

F1 是 Precision 和 Recall 的调和平均数。

### 2. 为什么不用普通平均数

调和平均数会惩罚短板。如果 Precision 很高但 Recall 很低，F1 不会被一个高值“拉得很好看”。

例如：

```text
Precision = 1.0
Recall = 0.1
F1 = 0.18
```

这说明模型虽然预测得准，但漏掉了大量正例。

### 3. 什么时候看 F1

- 类别不平衡。
- 正例识别很重要。
- 既不能误报太多，也不能漏报太多。

比如风控、故障检测、医学筛查、意图识别等场景。

### 4. 面试回答模板

```
F1 Score 是 Precision 和 Recall 的调和平均数，公式是 2PR/(P+R)。Precision 关注预测为正的样本里有多少是真的，Recall 关注真实正例里有多少被找出来。F1 的价值在于同时约束误报和漏报，尤其适合类别不平衡场景。它用调和平均数而不是算术平均数，是因为调和平均数会明显惩罚短板。
```

## 关键要点

1. Softmax 面试不能只背公式，要讲数值稳定性。
2. `CrossEntropyLoss` 通常已经内置 LogSoftmax。
3. 蒸馏的核心价值是学习软标签中的 Dark Knowledge。
4. 温度系数 `T` 越大，分布越平滑。
5. F1 用调和平均数，是为了惩罚 Precision/Recall 的短板。
