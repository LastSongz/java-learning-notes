# 01 - PyTorch 广播机制与 Attention 面试题

> 来源：`AI大模型面试突击班.pdf` 第 1-12 页。

## 一、PyTorch 的广播机制

### 1. 面试一句话

PyTorch 的广播机制允许不同 shape 的 Tensor 直接做逐元素运算，前提是从最后一个维度开始比较时，每一维都满足“相等、其中一个为 1、或者某个张量缺失该维度”之一。

### 2. 核心规则

从尾部维度向前对齐：

1. 两个维度大小相等，可以广播。
2. 其中一个维度大小为 1，可以被逻辑扩展。
3. 其中一个张量维度更少，缺失的前置维度可视为 1。

注意：广播是逻辑视图上的扩展，不会真的把数据复制很多份，所以既节省内存，也方便写向量化代码。

### 3. 典型例子

#### 标量和张量

```python
import torch

x = torch.tensor([[1, 2], [3, 4]])
y = x + 10
```

标量可以看成 0 维张量，能广播到任意形状。

#### 行向量和矩阵

```python
x = torch.tensor([[1, 2, 3], [4, 5, 6]])
bias = torch.tensor([10, 20, 30])

print(x + bias)
```

`bias` 的 shape 是 `(3,)`，可以广播到 `(2, 3)`，相当于给每一行加同一个行向量。

#### 列向量和行向量

```python
col = torch.tensor([[1], [2], [3]])  # (3, 1)
row = torch.tensor([[10, 20, 30]])   # (1, 3)

print(col + row)  # (3, 3)
```

这个例子常用于生成网格、外积、距离矩阵等。

### 4. 常见错误

`(3, 2)` 和 `(3, 3)` 不能广播，因为最后一维 `2 != 3`，并且两者都不是 1。

`(3, 4)` 和 `(3, 2, 4)` 可以广播：

```text
(   3, 4)
(3, 2, 4)
```

从后往前看：`4=4`，`3` 和 `2` 不相等也都不是 1，所以严格来说不能直接广播。要想广播，可以把 `(3, 4)` 调整为 `(3, 1, 4)`，再和 `(3, 2, 4)` 计算。

```python
x = torch.randn(3, 4)
y = torch.randn(3, 2, 4)

x = x.unsqueeze(1)  # (3, 1, 4)
z = x + y           # (3, 2, 4)
```

### 5. 面试回答模板

```
PyTorch 广播的本质是 shape 对齐。从最后一维开始比较，每个维度要么相等，要么其中一个是 1，要么缺失维度可以补成 1。广播不会真实复制数据，只是在计算时按逻辑扩展。比如矩阵加行向量时，行向量会扩展到每一行；如果维度不满足规则，就需要用 unsqueeze 调整维度。
```

## 二、Attention 是怎么计算的

### 1. 面试一句话

Attention 的核心是：每个 Query 去和所有 Key 计算相关性，经过缩放和 Softmax 得到权重，再用这些权重对 Value 做加权求和。

### 2. 标准公式

```text
Attention(Q, K, V) = softmax(QK^T / sqrt(d_k)) V
```

其中：

- `Q`：Query，表示“我想找什么信息”。
- `K`：Key，表示“我有什么特征可供匹配”。
- `V`：Value，表示“真正被聚合的信息内容”。
- `d_k`：Key 的维度，用来缩放点积结果。

### 3. 四步计算过程

#### 第一步：计算相似度分数

```text
Scores = QK^T
```

矩阵中第 `(i, j)` 个元素表示第 `i` 个 Query 和第 `j` 个 Key 的匹配程度。

#### 第二步：缩放

```text
ScaledScores = QK^T / sqrt(d_k)
```

如果不缩放，当 `d_k` 很大时点积结果会变大，Softmax 容易变得过于尖锐，导致梯度很小，训练不稳定。

#### 第三步：Softmax 归一化

```text
Weights = softmax(ScaledScores)
```

对每个 Query 的那一行做 Softmax，把相关性分数转成概率分布，所有权重加起来等于 1。

#### 第四步：加权求和

```text
Output = Weights V
```

每个 Query 根据注意力权重聚合所有 Value，得到融合上下文后的新表示。

### 4. 为什么 Q、K、V 要分离

如果强行让 `Q=K=V`，模型表达能力会受限制。分离后：

- `Q` 决定“我想关注谁”。
- `K` 决定“我适合被谁关注”。
- `V` 决定“我真正贡献什么内容”。

这让注意力关系可以更灵活、更非对称，表达能力更强。

### 5. 面试回答模板

```
Attention 可以按四步讲：先用 Q 和 K 做点积得到相关性分数，再除以 sqrt(d_k) 做缩放，避免 Softmax 过尖；然后对每一行做 Softmax 得到注意力权重；最后用权重乘 V，得到每个 token 聚合上下文后的表示。Q、K、V 分离的好处是把“我要找什么、我能被怎样匹配、我实际提供什么信息”拆开，提高表达能力。
```

## 关键要点

1. 广播规则从最后一维开始对齐。
2. `unsqueeze()` 常用于把 `(N,)` 调成 `(N, 1)` 或把 `(B, D)` 调成 `(B, 1, D)`。
3. Attention 公式是 `softmax(QK^T / sqrt(d_k)) V`。
4. 除以 `sqrt(d_k)` 是为了稳定 Softmax 和梯度。
5. Q/K/V 分离增强了注意力机制的表达能力。
