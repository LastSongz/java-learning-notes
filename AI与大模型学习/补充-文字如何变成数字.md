# 补充 - 数据如何变成向量

> 神经网络补充知识 | 2026-05-06

## 从文字到数字的完整流程

文字不能直接输入网络，需要经过三个步骤的转换。

### 第一步：分词（Tokenization）— 把句子切成小块

```
"我喜欢学AI" → [我, 喜欢, 学, AI]
"Today is a good day" → [Today, is, a, good, day]
```

每种模型有自己的"词表"（Vocabulary），每个 Token 有一个编号（ID）：

```
GPT-4 词表约 100,276 个 Token

Token "我"    → ID = 258
Token "喜欢"  → ID = 4321
Token "学"    → ID = 987
Token "AI"   → ID = 15532

"我喜欢学AI" → [258, 4321, 987, 15532]
```

> [!important] 为什么不能直接用编号？
> ID = 258（"我"）和 ID = 259（"恐龙"）编号相邻，但含义毫无关系
> ID = 5（"开心"）和 ID = 15000（"高兴"）编号很远，但意思接近
> 
> 直接用编号 → 模型会误解词义关系 → 需要下一步

### 第二步：Embedding（嵌入）— 编号变成有意义的向量

每个 Token ID 查一张"Embedding 表"，得到一个向量：

```
Token ID  →  向量（演示用4维，实际 768~12288 维）
─────────────────────────────────────
258 (我)    → [0.21, -0.55, 0.83, 0.12]
259 (恐龙)  → [-0.71, 0.33, -0.12, 0.91]
5 (开心)    → [0.65, 0.22, 0.78, -0.15]
15000 (高兴) → [0.63, 0.25, 0.76, -0.12]
```

**关键特性**：意思相近的词，向量也相近

```
"开心" [0.65, 0.22, 0.78, -0.15]
"高兴" [0.63, 0.25, 0.76, -0.12]  ← 非常接近

"我"   [0.21, -0.55, 0.83, 0.12]
"恐龙" [-0.71, 0.33, -0.12, 0.91]  ← 差很远
```

这张表是训练出来的：一开始随机 → 训练中词义相近的词自然聚在一起。

### 第三步：加上位置信息（Positional Encoding）

只有 Token 向量，模型分不清词序：

```
"我喜欢你" → [[我], [喜欢], [你]]
"你喜欢我" → [[你], [喜欢], [我]]
→ Token 向量一模一样，但意思完全不同！
```

解决方案：给每个位置加上"位置向量"：

```
最终输入 = Token 向量 + 位置向量

"我喜欢你"：
位置0: "我"的向量 + 位置0的向量
位置1: "喜欢"的向量 + 位置1的向量
位置2: "你"的向量 + 位置2的向量

→ 同样的词在不同位置 → 加不同的位置向量 → 数字不同 → 模型能区分顺序
```

### 完整流程

```
你输入: "我喜欢学AI"

① 分词（Tokenizer）
   "我喜欢学AI" → [我, 喜欢, 学, AI]

② 查编号
   → [258, 4321, 987, 15532]

③ 查 Embedding 表（每个 ID → 一个向量）
   → [[0.21,-0.55,0.83,0.12],
      [0.58, 0.31,0.67,-0.08],
      [0.12,-0.44,0.56, 0.33],
      [-0.35,0.78,-0.22,0.67]]

④ 加上位置编码
   → 每个向量 + 对应位置的向量

⑤ 送入神经网络（Transformer）
   → 层层计算 → 预测下一个 Token
```

### 为什么维度要那么高？

```
演示用 4 维，实际 GPT-3 用 12288 维

类比：
  2 维描述一个人：[身高, 体重] → 太少，分不清
  100 维：[身高, 体重, 年龄, 爱好, 性格, 学历, ...] → 够用

同样：
  4 维描述词 → 信息太少，很多词向量会撞车
  768 维 → 常见词够用（BERT）
  12288 维 → 细微差别都能表达（GPT-3）

→ 维度越高 → 表达能力越强 → 但计算量也越大
```

## 激活函数详解

### 为什么需要激活函数？

没有激活函数，不管叠多少层，都等价于一层的线性变换：

```
层1: z₁ = W₁·x + b₁
层2: z₂ = W₂·z₁ + b₂
代入: z₂ = (W₂·W₁)·x + (W₂·b₁ + b₂) = W'·x + b'
→ 依然是线性变换！多层毫无意义！
```

激活函数引入**非线性**，让网络能学习复杂模式。

### ReLU 为什么看起来线性，却能产生非线性？

单个 ReLU 在 x > 0 时确实是线性的。但多个 ReLU 组合就不线性了：

```
3 个 ReLU 神经元：
A: max(0, x)     ← x=0 处拐弯
B: max(0, x-2)   ← x=2 处拐弯
C: max(0, -x+4)  ← x=4 处拐弯

相加后的输出：
x<0:   0 + 0 + (-x+4) = -x+4    ← 一段直线
0≤x<2: x + 0 + (-x+4) = 4       ← 斜率变了！
2≤x<4: x + (x-2) + (-x+4) = x+2 ← 又变了！
x≥4:   x + (x-2) + 0 = 2x-2     ← 再变了！

→ 每个 ReLU 贡献一个"拐点"，组合成折线
→ 折线段数 = 神经元数量，越多越细腻
→ 足够多的 ReLU 可以逼近任意连续函数（万能逼近定理）
```

### 常用激活函数速查

| 场景 | 首选 | 原因 |
|------|------|------|
| LLM / Transformer 隐藏层 | GELU | 软门控，保留微弱信号 |
| 一般模型隐藏层 | ReLU | 简单快速 |
| ReLU 死亡神经元多 | Leaky ReLU | 负区间有梯度 |
| 二分类输出 | Sigmoid | 输出 0~1 概率 |
| 多分类 / LLM 输出 | Softmax | 输出概率分布 |

### ReLU 的局限性与替代方案

1. **死亡 ReLU**：负区间梯度为 0，神经元可能永远不更新 → Leaky ReLU 解决
2. **零点不可导**：尖角导致数值不稳定 → GELU 平滑过渡解决
3. **输出非零均值**：全是正数，收敛慢 → Tanh 零均值
4. **LLM 效果不如 GELU**：ReLU 硬截断丢弃信息，GELU 软门控保留微弱信号

## 导数（Derivative）

### 核心概念

导数 = **变化率** — 当输入稍微变一点点，输出变多少。

```
开车类比：
  时间:    0h    1h    2h    3h
  距离:    0km  60km  120km 180km
  
  速度 = 距离变化量 / 时间变化量 = 60 km/h
  → "速度"就是距离对时间的导数
```

### 图形含义

导数 = 曲线在某一点的**斜率**：

- 导数 > 0：函数在上升
- 导数 < 0：函数在下降
- 导数 = 0：到达极值点（谷底或山顶）

### 常见导数

```
函数          导数          直觉
──────────────────────────────────
f(x) = 5      f'(x) = 0    常数不变，变化率 = 0
f(x) = x      f'(x) = 1    变多少就是多少
f(x) = 2x     f'(x) = 2    x 变 1，结果变 2
f(x) = x²     f'(x) = 2x   x 越大变化越快
f(x) = xⁿ     f'(x) = nxⁿ⁻¹  幂函数求导法则
f(x) = eˣ     f'(x) = eˣ   导数等于自身
```

### 在神经网络中的作用

梯度 = Loss 对参数的**导数**（多参数时叫偏导数）：

```
dLoss/dw 告诉你：w 稍微变一点，Loss 会变多少

导数为正 → w 增大时 Loss 增大 → 应该减小 w
导数为负 → w 增大时 Loss 减小 → 应该增大 w
导数为 0 → 到谷底了

梯度下降：w_new = w - 学习率 × 导数（沿导数反方向走）
```

### 激活函数的导数特性

```
ReLU:  x>0 → 导数=1（梯度畅通）  x<0 → 导数=0（梯度消失，"死亡"）
Sigmoid: 两端导数≈0 → 深层网络梯度消失
→ 这就是为什么 ReLU 在深度网络中更好：正区间梯度恒为1
```

## 神经元如何"分工"

### 核心原理

网络不需要"选择"用哪些神经元。**所有神经元都参与计算**，不同神经元因权重不同，对不同输入敏感度不同。

```
3 个神经元，输入一张猫耳朵图片 [0.9, 0.8, 0.1]：

神经元A（尖形检测器）: 权重=[0.8, 0.8, -0.5], b=-0.3
  → 0.9×0.8 + 0.8×0.8 + 0.1×(-0.5) - 0.3 = 1.01 → ReLU = 1.01（兴奋！）

神经元B（圆形检测器）: 权重=[-0.3, 0.9, 0.9], b=-0.5
  → 0.9×(-0.3) + 0.8×0.9 + 0.1×0.9 - 0.5 = 0.04 → ReLU = 0.04（一般）

神经元C（直线检测器）: 权重=[0.5, -0.8, 0.3], b=0.1
  → 0.9×0.5 + 0.8×(-0.8) + 0.1×0.3 + 0.1 = -0.06 → ReLU = 0（无反应）

输出: [1.01, 0.04, 0] ← 神经元A 对"尖形"自然敏感
```

### 权重怎么变成"检测器"的？

通过训练：一开始随机 → 喂入大量数据 → 反向传播调整权重 → 逐渐分工。

没有人告诉神经元该检测什么，它们通过训练**自己学会**了分工。

## 多模态数据如何变成向量

### 图像 → 向量

图像**本来就是数字**——像素的 RGB 值。

```
一张彩色图片 = [高 × 宽 × 3] 的数字矩阵

例子：5×5 灰度图（0=黑 255=白）

  0   0   0   0   0
  0  255 255 255  0       ← 白色方块
  0  255 255 255  0
  0  255 255 255  0
  0   0   0   0   0

拉平：[0, 0, 0, 0, 0, 0, 255, 255, 255, 0, ...] → 25 个数字
```

实际中图片太大（手机照片 = 3千6百万个数字），所以：
1. 缩小图片（如 224×224）
2. 用 CNN 或 Vision Transformer 提取特征
3. 压缩成合理维度的向量（如 512 维）

这就是"图像 Embedding"。

### 音频 → 向量

音频本质是**声波的采样**。

```
1 秒音频，采样率 44100Hz → 44100 个数字（振幅）

可视化：
振幅
  |  /\
  | /  \  /\    /\
  |/    \/  \  /  \
  |          \/    \
  ——————————————————→ 时间
```

但直接用波形效果不好，通常转成**频谱图**：

```
梅尔频谱图（Mel Spectrogram）：
X轴 = 时间，Y轴 = 频率，颜色 = 能量

  频率
  高 |░░░░▓▓░░░░░░▓▓░░    ← 高频偶尔有声音
     |░░▓▓▓▓▓▓░░▓▓▓▓░░    ← 中频（人声区域）
  低 |▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓    ← 低频持续有声音
     ————————————————————→ 时间

→ 变成一张"图片"，用图像方法处理
→ Whisper（OpenAI 语音模型）就是这么做的
```

### 视频 → 向量

视频 = **图像序列 + 音频**。

```
10 秒 30fps 视频 = 300 张图片 + 10 秒音频

方法一：逐帧处理
  帧1→向量1, 帧2→向量2, ... → 向量序列 → Transformer 处理时间关系

方法二：时空一起处理
  相邻帧堆叠 → [H × W × 3 × T] → 同时学习空间和时间特征
```

### 万物皆可向量化

```
文本 → 分词 → Embedding → 向量
图像 → 像素 RGB → CNN/ViT 压缩 → 向量
音频 → 声波采样 → 频谱图 → 向量
视频 → 帧序列 + 音频 → 分别处理 → 向量序列
```

> [!important] 关键洞察
> 不管什么模态，最终都变成向量。向量就是"通用语言"。
> 文本向量、图像向量、音频向量在同一个空间里可以互相比较和交互。
> 这就是多模态模型（如 GPT-4o）能"看图说话"的原理。
