# 01 - AI、机器学习、深度学习的关系

> 第一阶段 · 第1课 | 2026-05-06

## 核心关系

它们是**层层嵌套**的关系：

```
人工智能 (AI)
  └── 机器学习 (ML)
        └── 深度学习 (DL)
              └── 大语言模型 (LLM)
```

## 人工智能 (AI) — 最外层的大伞

**定义**：让机器表现出"智能行为"的任何技术。

AI 不一定是"学习"出来的。早期的 AI 主要是**规则驱动**的：

```
例子：下棋程序（1997年的深蓝）
→ 程序员写死了规则：
   "如果对手走这步，我就走那步"
→ 它不会"学习"，只是算得快
```

所以 AI 这个概念从 1950 年代就有了，但很长一段时间都停留在"写规则"的阶段。

## 机器学习 (ML) — 让机器自己学

**定义**：不写死规则，而是给机器**数据**，让它自己找出规律。

```
传统编程：你写规则 → 机器执行
    输入: 照片
    规则: 如果有很多绿色像素 → 草地
    输出: "这是草地"

机器学习：你给数据 → 机器学出规则
    输入: 1万张标注了"草地/不是草地"的照片
    学习: 机器自己发现"绿色+纹理 = 草地"的规律
    输出: 能判断新照片里有没有草地
```

**关键转变**：从"人写规则"变成了"机器从数据中学规则"。

> [!important] 核心原则
> 没有好数据，就没有好模型。数据是机器学习的燃料。

## 深度学习 (DL) — 模仿大脑的学习

**定义**：机器学习的一种方法，用**多层神经网络**来学习，擅长处理图像、文本、语音等复杂任务。

```
为什么叫"深度"？
→ 因为神经网络有很多层（可以几十层甚至上百层）
→ "深" = 层数多

一个简单的神经网络长这样：

输入层    隐藏层1    隐藏层2    输出层
[像素] → [特征提取] → [高级特征] → [识别结果]
         (边缘)     (形状)     ("这是一只猫")
```

### 深度学习的突破（2012年左右开始）

- **图像识别**：ImageNet 比赛准确率从 74% → 85%+，碾压传统方法
- **语音识别**：Siri、小爱同学变得能用
- **自然语言处理**：翻译质量大幅提升

## 大语言模型 (LLM) — 深度学习在语言上的巅峰

**定义**：用海量文本数据训练的超大深度学习模型，能理解和生成人类语言。

### 发展简史

```
2017: Transformer 架构发明（Google论文 "Attention Is All You Need"）
      ↓
2018: GPT-1 诞生（OpenAI，1.17亿参数）
      ↓
2020: GPT-3（1750亿参数）— 突然变得很聪明
      ↓
2022: ChatGPT 发布 — AI 真正走入大众视野
      ↓
2024-2025: GPT-4o、Claude、Gemini、国产模型百花齐放
```

### LLM 的核心能力

| 能力 | 例子 |
|------|------|
| 理解语言 | "帮我翻译这段话" |
| 生成语言 | 写文章、写代码、写诗 |
| 推理 | 数学题、逻辑分析 |
| 知识问答 | "量子力学是什么？" |
| 遵循指令 | "用 Python 写一个爬虫" |

## 类比总结

```
AI    = 交通工具
ML    = 汽车（交通工具的一种）
DL    = 电动汽车（汽车的一种）
LLM   = 特斯拉（电动汽车的一种，当前最火的）
```

## 关键要点

1. **AI** 是大概念 → 让机器表现智能
2. **ML** 是方法 → 从数据中学，不写死规则
3. **DL** 是 ML 的一种 → 多层神经网络，处理复杂任务
4. **LLM** 是 DL 的应用 → 超大模型，处理语言任务
