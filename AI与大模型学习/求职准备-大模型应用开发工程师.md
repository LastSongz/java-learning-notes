# 求职准备 - 大模型应用开发工程师

> 职业规划 | 2026-05-06

## 岗位能力模型

```
大模型应用开发工程师
  ├── 基础能力（必须会）
  ├── 核心技能（岗位重点）
  └── 加分项（拉开差距）
```

## 一、必须掌握的基础

### 已掌握（15课内容）
- LLM 基本原理（Token、上下文窗口、温度等）
- Prompt Engineering（角色设定、Few-Shot、分步思考）
- API 调用（OpenAI 兼容接口，流式输出）
- Function Calling / Agent
- RAG 完整流程
- 微调概念（LoRA、QLoRA）
- Transformer 架构、KV Cache 等原理

### 还需补充
- Python 基础（有 Java 基础，转很快）
- LangChain / LlamaIndex 框架（实际开发主力）
- 向量数据库实操（Chroma / FAISS / Milvus）

## 二、核心技能（面试重点）

### Skill 1：RAG 系统（最重要，几乎必考）
- 文档加载（PDF/Word/网页）
- 文本分块（策略选择、chunk size 调优）
- Embedding 模型选择
- 向量数据库存储和检索
- 召回策略（相似度搜索 + 重排序）
- Prompt 组装和回答生成
- 评估方法（准确率、召回率）

### Skill 2：Agent 开发
- Function Calling 实操
- 多轮对话 + 工具调用
- ReAct / Plan-and-Execute 模式
- LangChain Agents / LangGraph

### Skill 3：Prompt Engineering
- Few-Shot / Chain-of-Thought
- 输出格式控制（JSON Mode）
- Prompt 模板设计
- 防幻觉策略

### Skill 4：模型部署与推理优化
- vLLM / Ollama 本地部署
- 模型量化（GGUF、AWQ、GPTQ）
- KV Cache 理解
- 并发和流式输出

## 三、项目经验（简历必须有 2~3 个）

### 项目1：企业知识库问答系统（RAG）
```
技术栈：Python + LangChain + Chroma + GLM API
功能：上传文档 → 分块向量化 → 自然语言提问 → 检索+生成
亮点：重排序（Reranker）、多路召回、评估指标
```

### 项目2：智能客服 Agent
```
技术栈：Python + LangGraph + Function Calling
功能：多轮对话 + 调用外部API + 自动选择工具 + 历史管理
亮点：人工接管、意图识别、多Agent协作
```

### 项目3：文档处理 Pipeline
```
技术栈：Python + PDF解析 + LLM API
功能：批量处理文档 → 信息抽取 → 分类 → 摘要生成
亮点：准确率评估、异常处理、高并发
```

## 四、简历要点

### 个人优势
"X年 Java 后端开发经验，熟悉 AI 应用开发，独立完成过 RAG 知识库系统和 Agent 项目"

### 技术栈
```
语言：Java、Python
框架：LangChain、LlamaIndex、Spring Boot
模型：GLM、Qwen、Llama、GPT-4o
向量库：Chroma、FAISS、Milvus
部署：vLLM、Ollama、Docker
其他：HuggingFace、PEFT
```

### 项目经验（STAR 法则）
- 情境（Situation）：背景是什么
- 任务（Task）：你负责什么
- 行动（Action）：具体怎么做的，用了什么技术
- 结果（Result）：量化成果（准确率XX%，处理XX次/天，节省XX小时）

## 五、面试常考问题

### 基础类
- Token 是什么？上下文窗口是什么？
- 什么是幻觉？怎么减少？
- Temperature 参数怎么调？
- 开源模型和闭源模型怎么选？

### RAG 类（重点）
- RAG 的完整流程？
- 文本分块策略？怎么选 chunk size？
- 向量检索和关键词检索的区别？
- 怎么评估 RAG 效果？
- 召回不准怎么优化？

### Agent 类
- Function Calling 的流程？
- Agent 和普通对话的区别？
- 怎么处理工具调用失败？
- 多 Agent 协作怎么设计？

### 工程类
- 怎么控制 API 调用成本？
- 流式输出怎么实现？
- 高并发下怎么优化？
- 怎么做 A/B 测试对比不同 Prompt？

### 架构类
- 什么场景用 RAG，什么场景用微调？
- 怎么设计多租户 AI 平台？
- 向量数据库怎么选型？
