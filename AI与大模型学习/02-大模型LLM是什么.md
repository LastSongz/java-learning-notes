# 02 - 大模型（LLM）是什么

> 第一阶段 · 第2课 | 2026-05-06

## LLM 的本质：猜下一个词

LLM 做的事情**本质上只有一件事**：

> 根据前面的内容，预测下一个最可能出现的 Token

```
输入: "今天天气"
候选: "很好" (85%)  "不错" (10%)  "真差" (3%)
输出: "很好"

→ 继续预测下一个 Token...
→ 最终生成: "今天天气很好，适合出去散步。"
```

当模型拥有几千亿参数 + 几万亿字训练数据 + 超强算力时，这个"猜下一个词"的能力就会变得极其强大——能写代码、做推理、回答复杂问题。

## Token — 大模型眼中的"字"

LLM 不按"字"或"词"处理文本，而是按 **Token**。

```
中文: "我喜欢学习AI" → [我, 喜欢, 学习, AI]  → 4 个 Token
英文: "I love learning AI" → [I, love, learn, ing, AI] → 5 个 Token
```

**经验法则**：

| 语言 | 1 个 Token 大约等于 |
|------|---------------------|
| 中文 | 1~2 个汉字 |
| 英文 | 4 个字母（约 0.75 个单词） |

> [!important] 为什么重要？
> - API 按 Token 计费
> - 模型有 Token 上限（上下文窗口）
> - 理解 Token 帮你估算成本和限制

## 上下文窗口（Context Window）— 模型的"短期记忆"

**定义**：模型一次能"看到"的最大 Token 数量。

```
类比：你在读一本书，但只能记住最近 N 页的内容
如果书超过 N 页，你就不记得前面的了
→ 这就是 LLM 的"遗忘"
```

### 各家模型的上下文窗口（2025年）

| 模型 | 上下文窗口 | 大约等于 |
|------|-----------|----------|
| GPT-4o | 128K Token | ~10万字中文 |
| Claude 3.5 | 200K Token | ~15万字中文 |
| Gemini 1.5 Pro | 1M Token | ~75万字中文 |
| 国产模型（通义/文心等） | 32K~128K | ~2.5万~10万字 |

### 实际影响

```
场景1：总结一本书
→ 书如果 20 万字，GPT-4o 就放不下，需要分段处理

场景2：长对话聊天
→ 聊了 50 轮后，模型可能"忘记"第1轮说了什么

场景3：RAG（后续课程）
→ 把大文档切碎，只喂给模型最相关的几段，绕过窗口限制
```

## 参数量（Parameters）— 模型的"脑容量"

**定义**：模型中可学习的数值数量，决定模型的容量和潜力。

```
参数量 ≈ 大脑中神经连接的数量
参数越多 → 理论上能记住和理解的东西越多
但     → 需要更多数据、更多算力、更多钱来训练
```

### 模型规模对比

| 参数量级别 | 代表模型 | 特点 |
|-----------|---------|------|
| ~1B（十亿） | 小模型 | 能跑在手机上，能力有限 |
| ~7B | Llama 3 8B | 开源，个人电脑能跑 |
| ~70B | Llama 3 70B | 需要专业显卡，能力不错 |
| ~几百B | GPT-4（估计） | 需要数据中心，能力很强 |
| ~万亿+ | GPT-4o、Gemini Ultra | 顶级模型，能力最强 |

> [!note] 关键认知
> 参数量 ≠ 越大越好。训练数据质量、训练方法同样重要。一个 70B 的好模型可以打败训练得差的 700B 模型。

## 温度（Temperature）— 控制"创意度"

**定义**：控制模型输出的随机性/创造性。

```
Temperature = 0（确定性）
→ 每次回答都一样，选概率最高的 Token
→ 适合：代码生成、事实问答、翻译

Temperature = 0.7（平衡）  
→ 大多数时候选合理的，偶尔有点变化
→ 适合：日常对话、写作辅助

Temperature = 1.5（创意性）
→ 更随机，可能产生意想不到的表达
→ 适合：创意写作、头脑风暴
```

**类比**：
- 温度低 = 严肃的大学教授 → 精确但无趣
- 温度中 = 聊天的朋友 → 自然流畅
- 温度高 = 喝醉的诗人 → 有创意但可能胡说

## LLM 工作的完整流程

```
你输入提示词（Prompt）
    ↓
[分词] 你的文字 → 变成 Token 序列
    ↓
[编码] Token → 转成数字向量（模型能理解的格式）
    ↓
[计算] 经过几十层 Transformer 层处理
    ↓
[预测] 输出下一个 Token 的概率分布
    ↓
[采样] 根据温度等参数，选择一个 Token
    ↓
[循环] 把新 Token 加到输入里，重复以上步骤
    ↓
[停止] 遇到停止符或达到上限，生成结束
    ↓
你看到模型的回答
```

> 每秒可生成几十个 Token，所以你感觉模型在"流式"回答。

## 关键要点

1. **LLM 本质** = 猜下一个 Token（规模大到产生质变）
2. **Token** = 模型的基本处理单位（中文约 1 字 = 1-2 Token）
3. **上下文窗口** = 模型一次能看到的最大 Token 数（短期记忆）
4. **参数量** = 模型的"脑容量"（越大理论上越强，但不是唯一因素）
5. **温度** = 控制输出的创意程度（0=精确，1+=创意）
