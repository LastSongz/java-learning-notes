# 12 - 微调技术：LoRA 与 QLoRA

> 第四阶段 · 第2课 | 2026-05-06

## 为什么不直接全量微调？

全量微调 = 更新模型的**所有参数**，显存需求巨大。

```
7B 模型全量微调：约需 70~80GB 显存 → 需要 3~4 张 A100
70B 模型全量微调：约需几百GB → 需要 8~16 张 A100

→ 个人开发者根本玩不起
```

## LoRA 核心思想

**不修改原权重，只训练两个小矩阵。**

```
全量微调：W_new = W_old + ΔW         ← ΔW 有70亿参数要学
LoRA：   W_new = W_old + A × B       ← A×B 只有几百万参数

类比：
  全量微调 = 整面墙重画
  LoRA = 原画不动，贴一层透明薄膜，只在薄膜上改
```

### 数学原理

```
原始权重 W：4096 × 4096 = 1678万参数

LoRA 引入两个小矩阵：
  A：4096 × 8   = 3.2万参数
  B：8 × 4096   = 3.2万参数

A × B → 得到 4096 × 4096 的矩阵
但参数量只有 6.5万 = 原来的 0.39%！

→ 只训练 0.39% 的参数，接近全量微调效果
```

### 秩（rank）的选择

```
rank = 8   → 简单任务（风格调整）
rank = 16  → 中等任务
rank = 64  → 复杂任务（学新知识）
rank = 128 → 非常复杂

rank 越大效果越好，但显存越多
实践中从 8 或 16 开始试
```

## LoRA vs 全量微调

```
              全量微调            LoRA
──────────────────────────────────────────
训练参数量     70亿              约 500万（0.07%）
显存需求       70~80GB           10~16GB
需要几张卡     3~4张 A100        1张 RTX 4090
训练速度       慢                快 2~3 倍
效果           最好              接近（差距很小）
训练成本       几万~几十万        几百~几千

→ LoRA 用 1% 的成本，达到 95% 的效果
```

## QLoRA — 再省 3 倍

```
LoRA：原始权重用 FP16（每个参数 2 字节）
QLoRA：原始权重压缩到 4-bit（每个参数 0.5 字节）

                    全量微调    LoRA      QLoRA
────────────────────────────────────────────────
7B 模型显存          70GB      16GB      6~8GB
70B 模型显存         几百GB    160GB     48GB
效果                100%      ~97%      ~95%

→ 7B + QLoRA → 一张 4090 就能微调
```

## 硬件需求

```
模型    QLoRA     LoRA      推荐显卡
──────────────────────────────────────
1.5B   ~2GB     ~4GB      RTX 3060
7B     ~8GB     ~16GB     RTX 4090
13B    ~14GB    ~28GB     2× RTX 4090
70B    ~48GB    ~160GB    2~4× A100
```

## 常用微调工具

```
LLaMA-Factory → 图形界面，零代码，推荐入门
Unsloth       → 速度快 2~5 倍，省显存
PEFT          → HuggingFace 官方 LoRA 库，灵活
trl           → HuggingFace 训练库，支持 SFT + DPO
```

## 什么时候该微调？

```
✅ 应该微调：
  - 需要改变行为风格
  - 需要学特定格式
  - 需要掌握垂直领域
  - Prompt + RAG 都不够好

❌ 不应该微调：
  - 只需要特定知识 → 用 RAG
  - 只需要特定格式 → 用 Prompt
  - 数据量很少 → 用 Few-Shot
  - 需求经常变 → RAG 更灵活

经验法则：Prompt → RAG → 微调（由简到繁）
```

## 关键要点

1. **全量微调太贵** → 显存不够
2. **LoRA** = 冻结原权重 + 只训两个小矩阵 → 参数量降到 0.1%
3. **rank** 控制小矩阵大小 → 8~64 常用
4. **QLoRA** = LoRA + 4-bit 量化 → 显存再省 3 倍
5. **7B + QLoRA** → 一张 4090 就能微调
6. **工具** → 新手 LLaMA-Factory，进阶 PEFT + trl
7. **大多数场景** → 先 Prompt + RAG，不够再微调
