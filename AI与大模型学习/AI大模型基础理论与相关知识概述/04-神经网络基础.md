# 04 - 神经网络基础

> 第二阶段 · 第1课 | 2026-05-06

## 神经元（Neuron）— 最基本的计算单元

一个神经元的计算过程：

```
输入: x₁, x₂, x₃  (数字)
权重: w₁, w₂, w₃  (数字，表示每个输入的重要性)
偏置: b           (数字，基准值)

步骤1: 加权求和
  z = x₁×w₁ + x₂×w₂ + x₃×w₃ + b

步骤2: 激活函数
  output = f(z)
```

### 类比：决定出不出去跑步

```
输入:
  x₁ = 天气好不好？（0~1 分）  w₁ = 0.5（你很在意天气）
  x₂ = 你有没有空？（0~1 分）  w₂ = 0.3
  x₃ = 心情好不好？（0~1 分）  w₃ = 0.2
  b = -0.4（你天生比较懒，需要推力）

计算:
  z = 0.8×0.5 + 0.6×0.3 + 0.9×0.2 + (-0.4) = 0.36
  0.36 > 0 → 去跑步！
```

核心：输入 × 权重 + 偏置 → 激活函数 → 输出

## 激活函数（Activation Function）

### 为什么需要激活函数？

没有激活函数时，不管叠多少层，最终等价于一层线性变换：

```
层1: z₁ = W₁·x + b₁
层2: z₂ = W₂·z₁ + b₂

代入后: z₂ = (W₂·W₁)·x + (W₂·b₁ + b₂) = W'·x + b'
→ 依然是线性变换！多层网络毫无意义！
```

**激活函数的作用 = 引入非线性，让网络能学习复杂模式。**

### 常用激活函数全览

#### 隐藏层常用

**1. ReLU（Rectified Linear Unit）** — 当今最流行
```
f(x) = max(0, x)

图形：
输出 |        /
     |       /
     |      /
     |     /
  ——+————/————→ 输入
     |  0

✅ 计算极快（只是比大小）
✅ 缓解梯度消失（正区间梯度恒为1）
❌ 负区间"死亡"（输出永远是0，不再学习）
```

**2. Leaky ReLU** — 解决 ReLU "死亡"问题
```
f(x) = max(αx, x)    α 通常取 0.01

图形：和 ReLU 类似，但负区间有小斜率（不是水平线）
✅ 负区间也有梯度，不会"死亡"
```

**3. GELU** — Transformer/LLM 标配
```
f(x) = x × Φ(x)    Φ 是标准正态分布的累积分布函数

和 ReLU 的区别：在 0 附近是平滑过渡（ReLU 是尖角）
✅ 平滑、处处可导
✅ 效果通常比 ReLU 好
使用：GPT、BERT、Llama 等几乎所有 LLM
```

**4. Swish** — Google 提出
```
f(x) = x × sigmoid(βx)
自门控机制，效果和 GELU 接近，视觉模型中更常用
```

#### 输出层专用

**5. Sigmoid** — 输出 0~1 概率（二分类）
```
f(x) = 1 / (1 + e⁻ˣ)

输出范围 (0, 1)，天然表示概率
✅ 二分类输出层
❌ 隐藏层中容易梯度消失（两端梯度趋近0）
❌ 输出不是零均值（收敛慢）
```

**6. Softmax** — 多分类输出层
```
把一组数字变成概率分布（所有值加起来 = 1）

输入: [2.0, 1.0, 0.1]
输出: [0.66, 0.24, 0.10]  ← 加起来 = 1

LLM 预测下一个 Token 时的最后一步就用 Softmax
```

**7. Tanh** — 输出 -1~1
```
f(x) = (eˣ - e⁻ˣ) / (eˣ + e⁻ˣ)
零均值，比 Sigmoid 收敛快
❌ 依然有梯度消失
现在主要用于 LSTM 等特殊场景
```

#### 特殊场景

**8. Mish** — 目标检测等视觉任务中表现好
```
f(x) = x × tanh(softplus(x))
比 GELU 更平滑，但计算更贵
```

### 选择速查表

```
隐藏层：
  LLM / Transformer  →  GELU（首选）
  CNN / 视觉模型      →  ReLU 或 GELU
  ReLU 死亡神经元多   →  Leaky ReLU
  想要更好效果        →  Swish / Mish（更贵）

输出层：
  二分类（是/否）     →  Sigmoid
  多分类（选一个）     →  Softmax
  回归（预测数值）     →  不用激活函数
  LLM（预测Token）    →  Softmax

谨慎使用 / 淘汰：
  Sigmoid 做隐藏层   → ❌ 容易梯度消失
  Tanh 做隐藏层      → ⚠️ 现在很少用
  阶跃函数           → ❌ 不可导，无法反向传播
```

### 为什么 ReLU/GELU 这么简单却这么有效？

```
Sigmoid/Tanh 的问题：
  输入很大或很小时 → 梯度趋近 0
  → 反向传播时梯度层层相乘 → 越来越小
  → 前面的层几乎学不到东西（梯度消失）

ReLU 的优势：
  正区间：梯度恒等于 1
  → 不管网络多深，梯度都能传过去
  → 深层网络也能有效训练

→ 这就是为什么"深度"学习在 ReLU 出现后才真正爆发
```

## 层（Layer）

```
输入层：接收原始数据（神经元数 = 特征数）
隐藏层：提取特征、学习模式（可以有几十上百层 → "深度"）
输出层：给出最终结果

例子 — 识别人脸：
第1层: 识别边缘、线条
第2层: 组合成形状（眼睛、鼻子）
第3层: 组合形状成部件
第4层: 识别整体（人脸）
```

## 前向传播（Forward Propagation）

数据从输入层 → 隐藏层 → 输出层，逐层计算。

```
输入 x
  ↓
层1: z₁ = W₁·x + b₁     a₁ = ReLU(z₁)
  ↓
层2: z₂ = W₂·a₁ + b₂    a₂ = ReLU(z₂)
  ↓
...
  ↓
输出层: output = Softmax(zₙ)  ← 输出概率分布
```

> W（权重矩阵）和 b（偏置向量）就是模型的"参数"。7B 模型 = 70亿个这样的 w 和 b。

## 损失函数（Loss Function）

衡量预测与真实的差距。

```
例子：预测图片是猫还是狗
真实: 猫 = [1, 0]

预测好: [0.8, 0.2] → Loss = -log(0.8) ≈ 0.32  ✓ 小
预测差: [0.1, 0.9] → Loss = -log(0.1) ≈ 2.3   ✗ 大

训练目标：让 Loss 尽可能小
```

## 反向传播（Backpropagation）

从输出层往回算，计算每个参数对 Loss 的"贡献"（梯度）。

```
类比：
做菜不好吃（Loss 大）→ 分析原因
→ 盐放多了？（w₁ 太大，梯度 +0.5 → 应该减小）
→ 火候不对？（w₂ 不合适，梯度 -0.3 → 应该增大）
```

数学本质：计算 Loss 对每个参数的偏导数。

## 梯度下降（Gradient Descent）

沿梯度方向调整参数，使 Loss 变小。

```
w_new = w_old - 学习率 × 梯度

类比：下山 → 看坡度（梯度），往最陡的下坡方向走一步

学习率太大 → 跳过谷底，来回震荡
学习率太小 → 走太慢
学习率合适 → 稳稳走到谷底
```

## 完整训练循环

```
for 每一轮（Epoch）:
    for 每批数据（Batch）:
        1. 前向传播: x → 层层计算 → 预测 ŷ
        2. 计算损失: Loss(ŷ, y_真实)
        3. 反向传播: 算梯度 ∂Loss/∂每个参数
        4. 更新参数: w = w - 学习率 × 梯度

重复很多轮 → Loss 越小 → 模型越准
```

### 训练 LLM 的规模

```
数据: 几万亿 Token
参数: 几十亿到上万亿
GPU: 成千上万张
时间: 几周到几个月
成本: 几百万到几千万美元
→ 这就是为什么只有大公司能训练大模型
```

## 关键要点

1. **神经元** = 加权求和 + 激活函数
2. **层** = 神经元组织在一起（输入层、隐藏层、输出层）
3. **前向传播** = 数据从前往后算预测
4. **损失函数** = 衡量预测与真实的差距
5. **反向传播** = 从后往前算每个参数的梯度
6. **梯度下降** = 沿梯度调整参数，减小 Loss
7. **训练循环** = 前向 → 算损失 → 反向 → 更新，反复进行
