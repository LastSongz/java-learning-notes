# 11 - 数据准备

> 第四阶段 · 第1课 | 2026-05-06

## 核心原则

> **数据比模型重要。** 数据质量决定了模型能力的上限。
> "Garbage in, garbage out"（垃圾进，垃圾出）

类比：模型 = 学生，数据 = 教材。学生再聪明，烂教材也学不好。

## 训练数据的三个阶段

对应第6课的三步训练法，每步用的数据完全不同：

```
预训练（读万卷书）
  数据量：几万亿 Token（整个互联网）
  要求：量大，质量过得去就行
  类比：读完整个图书馆

SFT 监督微调（学怎么回答问题）
  数据量：几万条问答对
  要求：量少但每条都是精品
  类比：请家教教考试技巧

RLHF（学人类偏好）
  数据量：几万条排序
  要求：人类标注"哪个回答更好"
  类比：老师改作文，告诉你哪篇更好
```

## 预训练数据处理

### 互联网原始数据很"脏"

```
原始网页：
  <div class="ad-banner">买一送一！！</div>
  <script>var x = function(){...}</script>
  <p>北京是中国的首都，位于华北平原...</p>  ← 只有这行有用
  <p>Copyright © 2024 All Rights Reserved</p>
  <p>手机：138xxxx1234 联系人：张三</p>
```

### 处理四步走

类比：买菜 → 洗菜 → 去坏 → 切好 → 下锅

```
原始数据
  ↓
① 清洗：去掉 HTML标签、广告、JS代码、个人信息
  ↓
② 去重：同一篇文章被转载100次 → 只留1次（通常去掉 20~30%）
  ↓
③ 质量过滤：留有实质内容的，丢垃圾
  ↓
④ 分词 → Token 序列 → 可训练
```

## SFT 数据：少而精（最关键）

### 一条 SFT 数据长这样

```json
{
  "instruction": "把下面的句子翻译成英文",
  "input": "今天天气很好",
  "output": "The weather is nice today."
}
```

### 两种制作方式

**方式1：人工标注（最靠谱）**

```
招标注员 → 给标注规范 → 手写问答 → 质检 → 修改 → 通过

优点：质量最高
缺点：贵、慢
成本：一条几块钱，2万条 ≈ 几十万
```

**方式2：用强模型生成（更常见）**

```
写好 Prompt → 让 GPT-4 生成大量问答 → 人工抽检 → 丢弃不合格的

优点：便宜、快、量大
缺点：质量可能不如人工
成本：一条几毛钱
```

> [!important] 最常见的错误
> ❌ 追求数量：100万条粗制滥造
> ✅ 追求质量：2万条精心制作 >> 100万条垃圾
> 
> 类比：100道乱出的题 vs 20道精编的题，后者对考试帮助更大

## 数据配比：不能偏科

```
典型配比：
  网页文本（新闻、博客）  60%   ← 语言基础
  书籍                   10%   ← 连贯性、深度
  代码（GitHub）         10%   ← 编程能力
  学术论文                5%   ← 专业知识
  百科（维基）            5%   ← 准确知识
  对话数据                5%   ← 对话能力
  其他                    5%

某个类型太少 → 模型那方面就弱：
  代码少 → 写代码差
  中文少 → 中文差
  数学少 → 数学差
```

## 数据质量评估

```
方法1：人工抽检
  随机抽 100 条 → 看格式、内容、正确性

方法2：统计指标
  平均长度 → 太短太长都不好
  词汇多样性 → 太少说明数据单一
  重复率 → 太高说明去重没做好

方法3：训了再看（最靠谱）
  用数据训一个小模型 → 跑分 → 分数高 = 数据好
```

## 国内数据合规

```
必须过滤：
  ✗ 违法违规内容
  ✗ 个人隐私（姓名、手机号、身份证）
  ✗ 政治敏感内容
  ✗ 暴力、色情内容

法规参考：《生成式人工智能服务管理暂行办法》
```

## 关键要点

1. **数据比模型重要** → 数据质量决定能力上限
2. **预训练数据** → 海量但脏，需清洗去重过滤
3. **SFT 数据** → 少而精，2万条精品 >> 100万条垃圾
4. **SFT 两种制作** → 人工标注或 GPT-4 生成
5. **数据配比** → 混合搭配，偏科会弱某方面
6. **国内合规** → 安全过滤必不可少
