# 06 - 训练过程：预训练到 RLHF

> 第二阶段 · 第3课 | 2026-05-06

## ChatGPT 的三步训练法

大模型不是一次训完的，而是三步走：预训练 → SFT → RLHF。

## 第一步：预训练（Pre-training）— "读万卷书"

**目标**：让模型学会语言的基本规律和世界知识。

```
训练方式：完形填空（预测下一个 Token）

输入: "中国的首都是___"       → 期望: "北京"
输入: "def add(a, b):\n    return___" → 期望: " a + b"
```

**训练数据**：互联网上的几乎所有文本（几万亿 Token）。

**预训练后能做什么**：续写文本。学会了语言规律 + 大量知识。

**预训练后的问题**：只会"续写"，不会"对话"。
```
你: "1+1等于几？"
模型: "2+2等于几？" ← 接着出题，而不是回答
```

## 第二步：SFT（Supervised Fine-Tuning）— "学规矩"

**目标**：教模型按照"提问→回答"的格式回复。

```
人工准备高质量问答对：

"什么是Python？" → "Python是一种高级编程语言..."
"写一个排序"     → "```python\nsorted([3,1,2])\n```"

→ 几万条高质量示例，继续训练模型
```

> [!important] 数据质量是关键
> SFT 数据不需要太多（几万条就够），但每条都必须高质量。OpenAI 早期雇了大量标注员来写这些问答。

类比：预训练 = 读书（学知识），SFT = 上课（学怎么回答问题）。

## 第三步：RLHF — "变得更好"

### 问题
SFT 后能回答了，但可能啰嗦、不准确、或输出有害内容。需要"人类品味"来进一步优化。

### 阶段 A：训练奖励模型（Reward Model）

```
1. 模型对同一问题生成多个回答
2. 人类标注员排序（A > C > B）
3. 用排序数据训练"打分模型"
   输入: 问题+回答 → 输出: 分数

回答A → 0.85 分（最好）
回答C → 0.65 分
回答B → 0.30 分（最差）
```

### 阶段 B：PPO 强化学习优化

```
循环：
1. 模型生成一批回答
2. 奖励模型打分
3. 高分 → 鼓励，低分 → 减少
4. 更新参数
5. 重复

→ 模型不断追求更高分数 → 回答越来越符合人类偏好
```

## 完整流程

```
预训练（几万亿 Token）
  ↓ 产出 Base Model（只会续写）
  ↓
SFT（几万条问答对）
  ↓ 产出 SFT Model（能对话）
  ↓
RLHF（人类排序 + 强化学习）
  ↓ 产出 Chat Model（好用、安全）
```

## 三阶段对比

```
             预训练              SFT              RLHF
────────────────────────────────────────────────────────
数据量       几万亿 Token        几万条问答         几万条排序
数据类型     互联网原始文本       人工高质量问答      人工排序偏好
训练成本     几百万~几千万美元    几万~几十万美元     几十万~几百万美元
训练目标     学语言+知识          学对话格式          学人类偏好
类比         读书                上课                实习
```

## 实际使用对应关系

```
Hugging Face 上的模型：

Meta-Llama-3-8B              ← Base Model（只会续写）
Meta-Llama-3-8B-Instruct     ← Chat Model（经 SFT + RLHF，能对话）

一般用的都是 Instruct 版本
自己做微调 → 从 Base Model 开始
```

## 关键要点

1. **预训练** = 海量文本学语言+知识 → Base Model（只会续写）
2. **SFT** = 人工问答对教对话格式 → SFT Model（能回答）
3. **RLHF** = 人类偏好+强化学习 → Chat Model（好用且安全）
4. 预训练成本最高，SFT 数据量小但质量要求极高
5. RLHF 让模型从"能回答"变成"回答得好"
6. 日常使用的都是 Chat/Instruct 版本
