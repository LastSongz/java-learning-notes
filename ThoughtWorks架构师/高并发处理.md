# 高并发处理

> 连接池、读写分离与一致性模型

## 连接池

### Python psycopg2

```python
from psycopg2 import pool

connection_pool = pool.ThreadedConnectionPool(
    minconn=5,
    maxconn=20,
    host='localhost',
    database='mydb'
)

conn = connection_pool.getconn()
try:
    cursor = conn.cursor()
    cursor.execute('SELECT * FROM users WHERE id = %s', (1,))
    result = cursor.fetchone()
finally:
    connection_pool.putconn(conn)  # 归还连接

# 关闭池
connection_pool.closeall()
```

## 主从复制与读写分离

```python
class DatabaseRouter:
    def __init__(self):
        self.master = redis.Redis(host='master-host')
        self.replicas = [
            redis.Redis(host='replica-1'),
            redis.Redis(host='replica-2'),
        ]
        self._index = 0
    
    def write(self, key, value):
        return self.master.set(key, value)
    
    def read(self, key):
        # 轮询到副本
        replica = self.replicas[self._index % len(self.replicas)]
        self._index += 1
        return replica.get(key)
    
    def read_strategic(self, key):
        # 关键读取，强一致，读主库
        return self.master.get(key)
```

### 限流算法

**令牌桶**：

```python
import time
import threading

class TokenBucket:
    def __init__(self, rate, capacity):
        self.rate = rate  # 每秒补充数量
        self.capacity = capacity
        self.tokens = capacity
        self.last_update = time.time()
        self.lock = threading.Lock()
    
    def acquire(self, tokens=1):
        with self.lock:
            now = time.time()
            elapsed = now - self.last_update
            self.tokens = min(self.capacity, self.tokens + elapsed * self.rate)
            self.last_update = now
            
            if self.tokens >= tokens:
                self.tokens -= tokens
                return True
            return False
```

**滑动窗口**：

```python
import time
from collections import deque

class SlidingWindowRateLimiter:
    def __init__(self, limit, window):
        self.limit = limit
        self.window = window  # 秒
        self.requests = deque()
        self.lock = threading.Lock()
    
    def is_allowed(self):
        with self.lock:
            now = time.time()
            cutoff = now - self.window
            
            # 移除窗口外的请求
            while self.requests and self.requests[0] <= cutoff:
                self.requests.popleft()
            
            if len(self.requests) < self.limit:
                self.requests.append(now)
                return True
            return False
```

## 面试常考问题

### Q: 连接池大小怎么设？
> 没有绝对标准。CPU密集型：核心数；IO密集型：核心数*2+。关键是压测调优，观察等待时间和CPU利用率。

### Q: 主从复制延迟怎么处理？
> 读敏感性高的读主库；延迟可接受的读从库；延迟检测超阈值告警；或用读写分离中间件自动路由。

### Q: 什么是一致性哈希？
> 将数据和节点映射到环形哈希空间，数据顺时针找到第一个节点。优点是节点增减只影响局部数据，适合分布式缓存。

### Q: 分布式锁怎么实现？
> Redis的SET NX EX或Redisson；ZooKeeper的临时有序节点；数据库唯一索引。需考虑：原子性、互斥、可重入、死锁。
