# 高级 Java 开发工程师补强学习计划

> 目标：围绕高级 Java 后端岗位，把当前知识结构从“能讲项目和核心八股”补强到“能解释生产级系统怎么运行、怎么治理、怎么排障”。

---

## 一、当前定位

你现在比较有优势的部分：

- DDD、遗留系统重构、Oracle 存储过程迁移、复杂业务建模。
- Java 并发、JVM、HashMap、Redis/MQ、MySQL/MVCC 已经有专题笔记。
- 供应链业务经验、用户中心权限治理、多级缓存、AI 助手项目可以作为面试主线。

当前主要短板不是 Java 基础，而是高级 Java 岗常追问的生产级能力：

- 网络、IO、NIO、Netty 等底层通信体系不成系统。
- Spring / Spring Boot / Spring Cloud 底层链路还偏原始材料，没有整理成自己的表达。
- 微服务稳定性治理：超时、重试、熔断、降级、限流、隔离、线程池保护。
- 数据库连接池、主从复制、读写分离、死锁、大表变更等工程化问题。
- 可观测性和线上排障体系：日志、指标、链路追踪、Arthas、GC log、jstack。
- Docker / K8s / CI/CD 有一些材料，但还没有形成 Java 后端交付视角。

---

## 二、学习原则

每个专题都按四步走：

1. **先建立主线**：这个技术解决什么问题，出现在系统哪一层。
2. **再学核心机制**：关键概念、底层流程、常见坑。
3. **绑定项目经验**：尽量和供应链、用户中心、AI 助手、SSE、多级缓存这些经历挂钩。
4. **形成面试产物**：每周至少沉淀 1 篇专题笔记、5 张闪卡、3 个可讲的面试回答。

每天建议节奏：

| 时间 | 任务 |
|---|---|
| 30 分钟 | 学一个核心概念 |
| 30 分钟 | 整理成自己的话 |
| 20 分钟 | 写 1-2 张闪卡 |
| 20 分钟 | 用项目经验组织一个面试回答 |

如果当天时间很少，只做一件事：把一个知识点讲成“问题背景 → 技术原理 → 项目落点 → 风险和取舍”。

## 三、8 周补强路线

### 第 1 周：网络、IO、NIO、Netty

目标：补齐当前最明显的空白。不要只背 BIO/NIO/AIO 区别，要能解释高并发连接为什么需要事件驱动。

学习重点：

- TCP 三次握手、四次挥手、粘包/拆包、KeepAlive、TIME_WAIT。
- HTTP/HTTPS、HTTP/1.1、HTTP/2、长连接、SSE、WebSocket。
- Java BIO、NIO、AIO 的差异。
- `Buffer`、`Channel`、`Selector`、直接内存。
- Reactor 模型：单 Reactor 单线程、单 Reactor 多线程、主从 Reactor。
- Netty 基础：EventLoop、ChannelPipeline、Handler、ByteBuf、零拷贝。

结合项目：

- 用 AI 助手的 SSE 流式输出解释 HTTP 长连接、超时、断开感知、线程占用。
- 用 Redis / Kafka 为什么快，串起 epoll、IO 多路复用、零拷贝。

产出：

- 新建专题笔记：`Java网络与NIO专题.md`。
- 新增闪卡：BIO/NIO、Selector、Reactor、Netty、SSE vs WebSocket。
- 能回答：“一个请求从浏览器到 Spring Boot 服务，中间经历了哪些网络和线程模型？”

---

### 第 2 周：Spring / Spring Boot / MyBatis 底层链路

目标：把 `msb` 里的框架源码材料整理成自己的面试表达。

学习重点：

- Spring IOC：BeanDefinition、BeanFactory、ApplicationContext、Bean 生命周期。
- 循环依赖：三级缓存为什么能解决 setter 注入，为什么不能解决构造器循环依赖。
- AOP：动态代理、JDK Proxy、CGLIB、切点、通知、事务代理。
- Spring 事务：传播行为、隔离级别、失效场景、`@Transactional` 自调用问题。
- Spring MVC 请求链路：DispatcherServlet、HandlerMapping、HandlerAdapter、Interceptor。
- Spring Boot 自动装配：`AutoConfiguration`、条件装配、starter。
- MyBatis：`#` 和 `$`、一级/二级缓存、Executor、插件机制。

结合项目：

- 用权限框架改造讲拦截器、AOP、数据权限。
- 用老系统重构讲事务边界为什么不能乱扩大。

产出：

- 整理专题笔记：`Spring核心链路面试整理.md`。
- 新增闪卡：Bean 生命周期、循环依赖、AOP、事务失效、MVC 请求链路。
- 能回答：“Spring Boot 一个接口请求进来后，从 Controller 到数据库大致经过哪些层？”

---

### 第 3 周：微服务调用链路与稳定性治理

目标：从“会说微服务组件”升级到“知道服务变慢、失败、流量突增时怎么保护系统”。

学习重点：

- API Gateway、Nacos、OpenFeign 的调用链路。
- 超时顺序：网关超时、Feign 超时、业务接口超时、数据库超时。
- 重试：什么时候能重试，什么时候不能重试，如何避免放大故障。
- 熔断：失败率、慢调用比例、半开恢复。
- 降级：返回兜底数据、异步化、关闭非核心能力。
- 限流：固定窗口、滑动窗口、令牌桶、漏桶、Sentinel 热点参数限流。
- 隔离：线程池隔离、信号量隔离、Bulkhead。

结合项目：

- 用 SSE + 大模型慢响应解释长连接资源保护。
- 用多级缓存解释热点 Key、击穿、降级。
- 用供应链重构解释为什么跨服务不能无限同步调用。

产出：

- 新建专题笔记：`微服务稳定性治理专题.md`。
- 新增闪卡：熔断、降级、限流、隔离、重试、超时。
- 能回答：“下游服务突然 RT 从 100ms 变成 5s，上游系统如何避免被拖垮？”

---

### 第 4 周：数据库工程化与连接池

目标：把 MySQL 从“会索引/MVCC”补到“能处理生产数据库问题”。

学习重点：

- HikariCP 连接池：最大连接数、最小空闲、连接泄漏、连接超时。
- CPU 密集型和 IO 密集型线程池/连接池配置思路。
- MySQL 主从复制、binlog、relay log、复制延迟。
- 读写分离：读到旧数据怎么办，哪些场景必须读主库。
- 死锁排查：事务顺序、索引命中、间隙锁、`show engine innodb status`。
- 大表变更：在线 DDL、分批迁移、灰度字段、回滚策略。
- 分库分表：分片键、一致性哈希、跨分片查询、分布式 ID。

结合项目：

- 用 Oracle 存储过程迁移讲事务边界拆分。
- 用 Outbox + CDC 解释数据库和 MQ 的最终一致性。

产出：

- 新建专题笔记：`数据库工程化与连接池专题.md`。
- 新增闪卡：HikariCP、主从延迟、死锁、大表变更、读写分离。
- 能回答：“线上数据库连接池打满，你怎么排查？”

---

### 第 5 周：Redis / MQ 深化与一致性

目标：你已有 Redis/MQ 笔记，本周重点是从“知道概念”变成“能做技术取舍”。

学习重点：

- Redis 持久化：RDB、AOF、混合持久化、恢复速度和数据丢失窗口。
- Redis 高可用：主从、哨兵、Cluster、脑裂风险。
- Redisson 分布式锁：看门狗、可重入锁、锁续期、锁误删。
- 多级缓存一致性：Caffeine + Redis + DB。
- RocketMQ：事务消息、延迟消息、重试、死信队列、顺序消息。
- Kafka：顺序写、页缓存、零拷贝、ISR、消费位点、消息积压。
- 幂等：唯一键、业务幂等号、版本号、状态机。

结合项目：

- 用用户中心权限缓存讲本地缓存失效和跨实例通知。
- 用 Outbox + CDC 讲可靠消息投递。

产出：

- 更新已有笔记：`中间件专题-Redis与MQ.md`。
- 新增闪卡：Redis Cluster、Redisson、RocketMQ 事务消息、Kafka ISR、消费幂等。
- 能回答：“数据库更新成功，但缓存和 MQ 状态不一致，怎么保证最终一致？”

---

### 第 6 周：可观测性与线上排障

目标：形成一套面试官最爱追问的排障方法论。

学习重点：

- 三件套：Logging、Metrics、Tracing。
- 指标：QPS、RT、TP95/TP99、错误率、线程池、连接池、GC、CPU、内存。
- 链路追踪：TraceId、Span、跨服务传播。
- 日志规范：关键字段、异常栈、业务 ID、用户 ID、租户 ID。
- JVM 排查：jstack、jmap、jstat、GC log、MAT、Arthas。
- 慢接口排查：网关、应用、线程池、数据库、Redis、MQ、外部依赖。
- CPU 100%、Full GC、OOM、死锁、线程池耗尽的排查步骤。

结合项目：

- 用 AI 助手流式输出讲长尾延迟监控。
- 用供应链定时任务优化讲性能瓶颈定位。

产出：

- 新建专题笔记：`线上排障与可观测性专题.md`。
- 新增闪卡：Trace、Metrics、CPU 100%、Full GC、慢接口、线程池耗尽。
- 能回答：“一个接口突然变慢，你如何从入口到数据库定位？”

---

### 第 7 周：Docker / K8s / CI-CD Java 后端视角

目标：不追求云原生专家，但要能听懂岗位 JD，并能讲清 Java 服务如何部署、发布、回滚。

学习重点：

- Dockerfile：基础镜像、分层、JAR 包构建、环境变量。
- Docker Compose：本地启动 Java + MySQL + Redis。
- K8s 基础：Pod、Deployment、Service、ConfigMap、Secret、Ingress。
- 健康检查：livenessProbe、readinessProbe。
- 发布策略：滚动发布、蓝绿、金丝雀、灰度、回滚。
- CI/CD：构建、测试、镜像、扫描、部署。
- DORA 四指标：部署频率、变更前置时间、变更失败率、恢复时间。

结合项目：

- 用 Spring Boot 服务打包部署讲镜像和配置管理。
- 用 Harness/Jenkins 对比讲企业交付治理。

产出：

- 新建专题笔记：`Java服务云原生交付入门.md`。
- 新增闪卡：Dockerfile、Pod、Service、Deployment、健康检查、灰度发布。
- 能回答：“一个 Spring Boot 服务从代码提交到上线，大概经历哪些步骤？”

---

### 第 8 周：安全、工程质量与综合面试演练

目标：把知识补强和简历项目串起来，形成可面试的高级 Java 叙事。

学习重点：

- 认证 vs 授权、Session、JWT、OAuth2、SSO。
- RBAC、ABAC、数据权限、租户隔离、越权防护。
- 接口安全：签名、防重放、限流、参数校验、SQL 注入、XSS、CSRF。
- 工程质量：单元测试、集成测试、Mock、契约测试、代码评审。
- SOLID 和设计模式：不要背定义，要能讲项目里怎么用、哪里踩过坑。
- 综合方案题：高并发接口设计、权限系统设计、AI 助手稳定性设计、缓存一致性设计。

结合项目：

- 用用户中心权限治理讲 RBAC/ABAC/数据权限。
- 用 AI 助手讲 Tool Registry、权限裁剪、二次校验和审计。

产出：

- 新建专题笔记：`权限安全与工程质量专题.md`。
- 新增闪卡：JWT、OAuth2、RBAC、ABAC、越权、单元测试、SOLID。
- 完成 2 轮模拟面试：一轮项目深挖，一轮系统设计。

## 四、优先级总表

| 优先级 | 专题 | 原因 | 建议投入 |
|---|---|---|---|
| P0 | 网络 / IO / NIO / Netty | 当前最明显空白，JD 高频出现 | 1 周 |
| P0 | Spring / Spring Boot 底层 | Java 高级岗必问，容易追深 | 1 周 |
| P0 | 微服务稳定性治理 | 高级岗和生产经验强相关 | 1 周 |
| P1 | 数据库工程化 | 能把 SQL 能力升级为生产排障能力 | 1 周 |
| P1 | Redis / MQ 深化 | 和你项目强相关，是可打主场 | 1 周 |
| P1 | 可观测性 / 排障 | 高级岗区分度很高 | 1 周 |
| P2 | Docker / K8s / CI-CD | JD 常出现，作为加分项补齐 | 1 周 |
| P2 | 安全 / 测试 / 工程质量 | 让项目表达更像高级工程师 | 1 周 |
