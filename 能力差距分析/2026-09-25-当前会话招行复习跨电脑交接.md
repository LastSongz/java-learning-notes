## Git同步步骤

远程：`https://github.com/LastSongz/java-learning-notes.git`。分支：`codex/learning`。

首次使用另一台电脑：

```bash
git clone --branch codex/learning https://github.com/LastSongz/java-learning-notes.git
cd java-learning-notes
git status --short
```

已有仓库或回到原电脑，先检查：

```bash
git status --short
git branch --show-current
git fetch origin
```

确认处于 `codex/learning`、相关工作区改动已妥善保存且可以快进，再执行：

```bash
git pull --ff-only origin codex/learning
```

遇到本地未提交内容或分叉，先核对差异、保留两边学习流水；不擅自reset、覆盖、stash或force push。原电脑有无关未提交文件，不要求整个仓库必须清空，也不要顺便提交。

仅在用户要求/明确授权后提交并推送，今天的授权不代表所有后续回合自动同步：

```bash
git add -- "能力差距分析/2026-09-16-招行外包Java面试三天突击与进度跟踪.md"
git diff --cached --name-only
git diff --cached --check
git commit -m "docs: update interview study progress"
git push origin codex/learning
```

先检查暂存区是否有无关内容，提交范围只包含本人授权的学习文件。push未成功就不能称另一台已可获取。没有终端能力的GPT提供修改块，由用户保存同步。
