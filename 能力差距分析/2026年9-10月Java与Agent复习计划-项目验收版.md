# 2026 年 9—10 月 Java 与 Agent 复习计划（项目验收版）

> 目标：为成都税前现金总包不低于 21 万的高级 Java、Java + Agent 和 Agent 应用开发岗位做系统复习。
>
> 时间条件：复习时间按工作日每天 1—2 小时、周末每天 3—4 小时，即每周约 14 小时；项目时间额外安排。
>
> 项目边界：Flower Chat Agent 由自己单独执行，本计划不安排项目开发任务，只在约定日期做阶段验收、演示检查和项目答辩。

总清单：[[能力差距分析/2026年9-10月成都Java与Agent招聘季复习清单|2026 年 9—10 月成都 Java 与 Agent 招聘季复习清单]]。

---

## 一、计划边界

### 本计划包含

- [ ] 高级 Java 高频知识复习。
- [ ] Agent、LangGraph、MCP、RAG 和 AI 工程化复习。
- [ ] 简历表达、项目口述、系统设计和模拟面试。
- [ ] JD 分析、精准投递和真实面试复盘。
- [ ] Flower Chat Agent 的定期只读检查、测试、演示和答辩验收。

### 本计划不包含

- Flower Chat Agent 的具体编码步骤。
- 项目功能拆解、每日开发任务和代码实现指导。
- 项目的开发时间估算和开发进度管理。
- 为了勾选计划而重复创建已有笔记。
- 与目标岗位无关的算法训练、模型预训练和大规模 GPU 部署。

项目执行出现阻塞时，单独进入项目上下文解决；解决完成后再回到本计划，不把开发问题扩散到复习节奏中。

## 二、时间安排

### 8 月 10 日—8 月 31 日：完整复习，项目额外执行

8 月开始即按每周 14 小时完整复习，Flower Chat Agent 的开发与阶段验收使用额外时间：

- [ ] 高级 Java：每周 6 小时。
- [ ] Agent / RAG / MCP：每周 4 小时。
- [ ] 模拟面试与项目口述：每周 2 小时。
- [ ] JD 分析与投递预热：每周 1 小时。
- [ ] 闪卡与周复盘：每周 1 小时。

### 9 月 1 日—10 月 31 日：完整复习节奏

每周按 14 小时安排：

| 方向 | 每周时间 | 主要产出 |
|---|---:|---|
| 高级 Java | 5 小时 | 原理口述、项目案例、系统设计 |
| Agent / RAG / MCP | 3 小时 | 原理口述、项目绑定回答、失败场景 |
| 模拟面试 | 2 小时 | 自我介绍、项目深挖、综合追问 |
| JD 与投递 | 2 小时 | 岗位分析、定向准备、投递记录 |
| 面试复盘 | 1 小时 | 缺口修复、错题和话术更新 |
| 周复盘 | 1 小时 | 更新下周 P0，不平均补所有专题 |

### 8—10 月参考日程

- [ ] 周一 1.5 小时：Java 原理。
- [ ] 周二 1.5 小时：Agent / RAG / MCP。
- [ ] 周三 1.5 小时：Java 项目案例或系统设计。
- [ ] 周四 1.5 小时：模拟面试。
- [ ] 周五 1 小时：JD 分析、闪卡和错题。
- [ ] 周六 3.5 小时：Java 专题深挖与综合口述。
- [ ] 周日 3.5 小时：Agent 专题、精准投递和周复盘。

项目开发和阶段验收均使用额外时间，不从以上 14 小时复习预算中扣除。

## 三、每周固定产出

每周结束前至少完成：

- [ ] 5 道 Java 高频题口述。
- [ ] 3 道 Agent/RAG/MCP 题口述。
- [ ] 1 个自己的项目案例回答。
- [ ] 1 道系统设计或线上排障题。
- [ ] 1 次 30—45 分钟模拟面试。
- [ ] 分析至少 3 个真实 JD，9 月开始按计划投递。
- [ ] 新增或更新 5 张真正来自薄弱点的闪卡。
- [ ] 周日只保留最多 3 个下周 P0 缺口。

复习完成的判断标准不是“读过笔记”，而是能够脱离笔记，用“背景—原理—项目落点—失败模式—取舍”完整回答。

## 五、项目阶段验收统一流程

每次验收控制在 30—60 分钟，只做下面五件事：

1. 查看 Git 状态、最近提交和本阶段变更范围。
2. 按项目 README 运行对应测试、构建或演示命令。
3. 检查黄金链路、错误场景和关键证据。
4. 随机提问 3—8 道项目答辩题，判断是否真正理解。
5. 记录验收结论：通过、有条件通过或不通过，并列出最多 3 个缺口。

## 六、真实面试反馈如何改变计划

每次面试后 24 小时内：

- [ ] 记录所有能回忆的问题。
- [ ] 标记为“不会 / 原理会但不会结合项目 / 表达混乱 / 回答正确”。

- [ ] 面试已经证明掌握的内容降低复习频率，不重复消耗时间。

## 八、执行原则

1. 8 月开始即执行完整复习；项目开发与验收使用额外时间。
2. 9 月开始必须边投递边复习，不等待知识全部学完。
