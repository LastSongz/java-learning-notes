# New Computer Setup

This project is prepared for migration through Git plus a Codex handoff file.

## Clone The Project

On the new computer, run:

```powershell
git clone https://github.com/LastSongz/java-learning-notes.git
cd java-learning-notes
git checkout codex/learning
```

## Resume The Codex Interview Session

Open this project folder in Codex on the new computer, then read:

```text
codex-handoffs/session-019ebbce-4627-7b72-865c-e8330f34da33.md
```

Start a new Codex thread with:

```text
请从 codex-handoffs/session-019ebbce-4627-7b72-865c-e8330f34da33.md 继续这个会话。先继续点评我最后关于“工单上传为什么不能放进工单聚合”的回答，然后继续模拟面试追问。
```
